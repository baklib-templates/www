# WWW 官网模板

[English](README.md) | 简体中文

这是企业品牌官网。内容写在站点页面上：首页讲主张，频道收栏目，文章放正文。适合公司官网、营销页和内容门户。不适合产品文档，也不适合发帖社区。

要知道结构、字段和怎么用，按顺序读 `docs/`。本文件对应的英文 README 后半是安装和构建，不要从那里推断内容模型。

| 文件 | 读它是为了 |
| --- | --- |
| [docs/README.md](docs/README.md) | 分册目录 |
| [docs/overview.md](docs/overview.md) | 是什么、什么场合用 |
| [docs/structure.md](docs/structure.md) | 首页、频道和文章 |
| [docs/schema.md](docs/schema.md) | 字段 id，以及能不能改 |
| [docs/usage.md](docs/usage.md) | 建站后怎么配 |
| [docs/activation.yml](docs/activation.yml) | 快速开始的编排配方 |

视觉和构建见 [README.md](README.md)。示例站点数据在 `seeds/`，编排配方不在那里。
