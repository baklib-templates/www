# 从客户资料组装 WWW 首页

1. **确定访客和行动。** 记下谁会打开首页、要判断什么、应该点到哪里。把现有产品介绍、可公开的作品、可引用的数据和有效链接放到相应问题下。
2. **选择阅读顺序。** 从[行业首页](skill/references/homepage-patterns.md)找一个相近的访客任务。品牌策略先讲方法，视觉工作室先给作品，内容营销优先搜索和文章。按本站材料取舍原页中的各段。
3. **选到具体组件。** 在[组件目录](skill/references/components.md)比较布局、数量和依赖。从 `index.sections` 组装时，核对实际启用的 render 与展示顺序。运营需要通过 AI 持续修改的区块，可将所选组件源码展开到本站首页，保留来源和区块标识，后续按实例改标题、图片和按钮。
4. **填入内容。** 产品、服务、方法可直接根据客户资料写入区块。作品需授权图片，列表需确认来源与实际页面路径；客户只要栏目架构时把空栏目放在导航，首页仍可提供产品介绍、应用场景、使用步骤和有效的行动入口。
5. **从访客视角走一遍。** 在桌面和手机上读首屏、点主按钮、操作筛选和轮播。检查演示文案、占位链接、空列表标题及重复 ID。涉及咨询或订阅时实际验证提交和反馈。

查看已有站点时先确认采用的是哪个首页变体，以及正文来自页面字段、栏目查询还是模板源码。字段清单见[页面 Schema](schema.md)，站点内的局部修改见[工作台维护](skill/references/workbench.md)。
