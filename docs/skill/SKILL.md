# WWW 企业官网模板 Skill

给 AI 和模板维护者阅读。快速开始按本文和 `manifest.yml` 把一句业务描述变成一个有栏目、有动态页面的企业官网。

## 定位

适合需要对外展示品牌、产品或服务，并持续发布案例和新闻的企业。访客通过页头导航进入栏目，在首页看到最新内容。

不适合：

- 产品手册、帮助中心、API 文档：用文档模板。
- 用户发帖、问答讨论：用社区模板。
- 以图片、视频、文件下载为主的素材门户：用资源门户模板。
- 在线下单、支付、会员积分：模板没有这些能力。

## 信息架构

站点固定三层：首页 → 栏目 → 文章。

| 页面类型 | 用途 | 下级 |
| --- | --- | --- |
| 首页（区块组合） | 首屏加 6 个可选区块 | 只能挂栏目 |
| 卡片栏目 `channel` | 案例、解决方案、新闻，按配图卡片展示 | 文章或子栏目 |
| 列表栏目 `channel.list` | 服务项目、产品系列 | 文章 |
| 侧栏栏目 `channel.side` | 关于我们、联系我们等少量说明 | 侧栏文章 |
| 文章 `page` / 侧栏文章 `page.side` | 正文 | 无 |

页头导航由一级栏目自动生成，页脚导航按一级栏目分组列出其下文章，不需要手写菜单。

常见行业范式见 `manifest.yml` 的 `industries`，每个行业都有一份完整的示例站。

## 首页区块

首屏字段：`hero_title`（20 字以内）、`hero_description`（80 字以内）、主按钮和次按钮文字。

6 个区块槽位，每个槽位选一种类型：

- `latest`：按发布时间列出某个栏目的最新文章，适合新闻、博客、动态。
- `cards`：以配图卡片列出某个栏目的文章，适合服务、产品、案例。
- `html`：一段静态 HTML，适合优势、流程、原则、常见问题、引言。
- `off`：不显示。

`latest` 和 `cards` 必须指向真实存在的栏目路径，例如 `/news`。首页至少要有两个动态区块，否则首页就退化成静态页。

### HTML 区块写法

只允许以下标签：`div` `section` `h2` `h3` `h4` `p` `ul` `ol` `li` `a` `strong` `em` `span` `br` `blockquote` `cite` `details` `summary`。

只允许 `wx-` 开头的样式类，其他类名、`style`、脚本、图片、表单会被移除。链接只能是站内路径或 `https://` 地址。

| 写法 | 结构 |
| --- | --- |
| 优势卡片 | `<div class="wx-grid wx-grid-3">` 内放多个 `<div class="wx-card"><span class="wx-icon">1</span><h3>…</h3><p>…</p></div>`，也可用 `wx-grid-2` / `wx-grid-4` |
| 流程步骤 | `<ol class="wx-steps">` 内放 `<li class="wx-step"><span class="wx-step-number">1</span><h3>…</h3><p>…</p></li>` |
| 要点清单 | `<ul class="wx-list"><li>…</li></ul>` |
| 常见问题 | `<div class="wx-faq">` 内放 `<details><summary>问题</summary><p>回答</p></details>` |
| 引言 | `<blockquote class="wx-quote">…<cite>来源</cite></blockquote>` |
| 数据 | `<div class="wx-stats">` 内放 `<div><span class="wx-stat-value">…</span><span class="wx-stat-label">…</span></div>` |
| 段落 | `<p class="wx-text">…</p>`，强调链接 `<a class="wx-link">` |

区块标题写在区块的标题字段里，HTML 里不要再写 `h2` 标题。

## 写作规范

- 用企业自己的口吻（"我们"），短句，直接说明能为客户解决什么。
- 栏目名 2 到 6 个字；栏目说明一句话。
- 文章正文用 `h2`、`p`、`ul`、`ol`，每篇 100 到 300 字，不写空话。
- 页面路径用小写英文和短横线，栏目路径不改。

## 事实边界

- 客户描述里没有的具体数字、资质、奖项、客户名称、合作伙伴、联系方式一律不写。
- 案例和新闻栏目是示例内容：客户名称只能写"某制造企业"这类泛称，结果数据保持示例性质，客户上线前会替换。
- 只有客户描述提供了数据时才使用数据区块，否则改用优势、流程或原则区块。
- 联系方式页保留"请填写联系电话"一类占位，由客户填写。
- 模板没有在线表单，不要写"提交后立即获得"之类无法兑现的动作。
