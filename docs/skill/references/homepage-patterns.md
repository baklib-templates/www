# 11 个行业首页的组装经验

每个条目的“原页顺序”按当前模板正文从上到下记录。“选用”给出可用独立组件和取舍，编号见[组件目录](components.md)。行业模板大多把区块写在页内，同名题材的组件可能有不同的数据来源。先确定访客需要看见的证据，再借用合适的顺序。

下列原页顺序用于研究构图，各例选用序列列出该场景的主要区块。用于 get-started 时按[模板技能](../SKILL.md)补齐 Hero、动态博客与独立 CTA，已有的同类实例计入必选项。

## 先辨认首页的数据来源

广告、品牌、创意、数字服务、平面、移动应用、RTL、SEO、社媒这九个模板的大部分服务、项目、人物、数字和引言直接写在页面内。首页开头即使给 `service_page`、`about_page` 等变量赋值，也要检查相应区块是否实际读取它们。品牌模板里的示例文章就是静态卡片，独立的 blogs 组件则会执行查询。

营销与网站设计两个模板实际读取栏目和站内列表。它们的最新内容先按创建时间取 8 条，再跳过置顶或推荐项，热门推荐按访问量取 10 条。这两路数据与独立 blogs 组件的发布时间查询有不同的筛选范围和顺序。

## 广告投放 · advertising

**原页顺序**　投放主张 → 服务 → 平台占比进度条 → 数字 → 套餐 → 行动按钮 → 品牌标志。[广告模板](../../../templates/index.advertising.liquid)

**选用**　有标准化投放服务和公开报价时，用 `hero2 → services1 → pricing1 → cta1`，让访客先看服务范围，再比较预算。原页的进度条写在模板内，组件库没有同款。占比需要明确分母，效果数字需要统计周期；没有这些资料时，用 `process1` 解释从诊断到复盘的步骤。按项目询价时让按钮直接通往咨询。

## 品牌策略与识别 · branding

**原页顺序**　品牌主张与图片轮播 → 三点品牌方法 → 识别、命名等服务 → 作品 → 文章 → 品牌标志。[品牌模板](../../../templates/index.branding.liquid)

**选用**　客户要了解“为什么这样设计”时，可用 `hero3 → content1 → services2 → portfolio2`。用同一项目的几张授权画面呈现设计语言，在方法段说明依据，再用作品对应方法。只有一张主视觉时用单图首屏；有品牌手册和方法介绍但暂无公开案例时，让方法和交付物承担首页主体。

## 创意代理 · creative

**原页顺序**　创意主张 → 工作室介绍 → 品牌标志 → 服务 → 作品 → 客户评价 → 联系与地图。[创意模板](../../../templates/index.creative.liquid)

**选用**　以风格争取委托的工作室可用 `hero4 → content2 → portfolio1 → cta4`，首屏分别通往作品和服务，正文用一段话交代擅长的委托类型。跨多个设计门类时补 `services4`。没有公开合作标志或具名评价时，让已获授权的创作成果直接接到项目咨询。

## 综合数字服务 · digital

**原页顺序**　代理服务主张 → 品牌标志 → 公司介绍 → 服务 → 作品 → 数字 → 评价 → 文章 → 业务咨询邀请。[数字代理模板](../../../templates/index.digital.liquid)

**选用**　覆盖开发、营销、搜索等多项业务时，用 `hero5 → content3 → services3 → portfolio2 → download3`。服务段按客户需求分组，作品说明哪项服务解决了哪个问题。`download3` 实际是业务邀请版式，要替换示例链接。项目少时用一个项目讲清服务组合；博客可用 `blogs1` 动态展示最近文章。

## 平面设计工作室 · graphic

**原页顺序**　设计主张 → 最新作品 → 设计服务 → 团队 → 合作邀请 → 文章 → 联系。[平面设计模板](../../../templates/index.graphic.liquid)

**选用**　访客靠视觉判断是否委托时，保留作品紧跟首屏的顺序，如 `hero6 → portfolio2 → services4 → cta4`。有足够多且分类清晰的作品，使用分类网格；少量系列作品可用 `portfolio3`，写清每组图代表的项目。有署名创作者和肖像授权时再加 `team1`。

## 内容营销与站内发现 · marketing

**原页顺序**　可搜索首屏 → 品牌标志 → 服务栏目 → 关于栏目 → 可选 HTML → 搜索行动区 → 最新内容与热门推荐。末段虽标为 CONTACT，实际输出文章列表。[营销模板](../../../templates/index.marketing.liquid)

**选用**　资料较多、访客带问题进站时保留原页的站内搜索。服务取自 `/services` 的导航子页，关于取自 `/about`；缺栏目时模板会显示演示片段。要做以获客为主的简版，可用 `hero4 → services5 → blogs2 → cta2`，将按钮指向真实落点。独立 `blogs2` 是按发布时间排列的图文列表；若仍要最新与热门两种排序，保留原页的两路查询。栏目留空时保留博客空态，用能力说明充实服务段。

## 移动应用开发或产品展示 · mobile-app

**原页顺序**　设备画面首屏 → 开发服务 → 开发步骤 → 项目截图轮播 → 洽谈邀请 → 客户评价。[移动应用模板](../../../templates/index.mobile-app.liquid)

**选用**　外包开发团队可用 `hero8 → services6 → process1 → slider2 → cta4`，让采购方看到能交付什么、如何合作、成品什么样。若推广的是已上架应用，把开发服务换为用户功能，把末段换成 `download1` 并链接具体应用商店详情页。截图不足以支撑轮播时，一张真实界面配功能说明即可。

## 模板产品展示与 RTL 场景 · rtl

**原页顺序**　产品预览首屏 → 预建首页样例集 → 选择理由 → 一次性授权价格 → 模板功能 → 开始使用。[RTL 模板](../../../templates/index.rtl.liquid)

**选用**　这份源码展示的是可试看的模板产品。可用 `hero1 → portfolio1 → features1 → pricing2 → cta3`，作品网格须改为能打开真实预览的样例卡；原页的样例集、授权比较和长功能清单应分别核对。没有公开定价时改为授权咨询。RTL 是阅读方向，面向从右到左语言时，还需在目标语言下检查导航、箭头和轮播方向。

## SEO 专业服务 · seo

**原页顺序**　服务对象 → SEO 服务 → 视频 → 团队 → 数字 → 常见问题 → 客户评价 → 联系与地图。[SEO 模板](../../../templates/index.seo.liquid)

**选用**　需要解释交付范围的专业服务，可用 `hero9 → services7 → fax1 → cta4`。FAQ 写清审计包含什么、由谁实施、怎样报告；有方法演示视频可在服务后加 `video1`，有公开团队资料再用 `team2`。排名、流量和回报增长只展示有来源、周期及口径的结果。

## 社交媒体运营 · social-media

**原页顺序**　社媒主张 → 投放与转化数字 → 服务 → 代表作品 → 咨询 → 评价 → 品牌标志。[社媒模板](../../../templates/index.social-media.liquid)

**选用**　有可披露活动数据时可用 `hero10 → counter5 → services8 → portfolio1 → cta4`，让访客先看覆盖与转化，再看相关创意。为每个数字标明平台、时间和含义。客户只授权了创意素材时，将作品提前到首屏之后，直接展示平台适配和内容风格。

## 网站设计与建设 · web-design

**原页顺序**　双幅轮播 → 指标 → 品牌标志 → 关于 → 服务 → 最新内容与热门推荐 → 搜索行动区。PORTFOLIO 段读取全站页面；开头赋值的 `portfolio_page` 未用于列表。[网站设计模板](../../../templates/index.web-design.liquid)

**选用**　重在呈现交付作品时，可用 `slider1 → portfolio3 → services3 → cta4`，每幅图链接对应项目。重在内容发现时保留原页的最新与热门列表。原页从页面设置读取两张轮播的标题、图片和链接；`counter_lines` 超过一行才输出指标，格式为“数值|说明”。只有一个项目时改用单幅首屏。独立 `slider1` 提供轮播构图，两套页面设置需分别绑定。
